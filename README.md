# 微观经济指标对消费支出的影响分析

> 基于描述性统计与矩阵多元线性回归的家庭消费行为研究 · Python 课程期末项目

本项目以 **1200 户家庭**的微观调查数据为样本，研究**家庭年收入、资产总值与消费者信心指数**对**消费支出**的影响。核心回归模型不依赖现成回归库，而是使用 NumPy 矩阵运算手工实现最小二乘法（OLS）解析解，并手工计算拟合优度 R²，完整覆盖"数据清洗 → 描述性统计 → 可视化 → 建模 → 模型评估"的分析流程。

## ✨ 功能特性

- **数据校验与清洗**：文件存在性检查；均值填补缺失值；基于经济学逻辑（金额非负）识别并修正负数异常值
- **手工描述性统计**：用循环结构计算均值、样本方差、标准差与极差，不直接调用统计库
- **收入分层**：按年收入将家庭划分为高 / 中 / 低三个阶层（`for` + `if-elif-else` 控制流）
- **多维可视化**：2×2 图表矩阵，含条形图、带趋势线的散点图（两组）、分层箱线图
- **矩阵法多元回归**：设计矩阵含截距列，通过 β = (XᵀX)⁻¹XᵀY 求解系数，内置矩阵不可逆（多重共线性）异常处理
- **拟合优度检验**：逐样本循环计算 SST 与 SSR，得出决定系数 R²

## 🧮 核心方法

**模型设定**（含截距项的设计矩阵 X）：

```
消费支出 = β₀ + β₁·年收入 + β₂·资产总值 + β₃·信心指数 + ε
```

**OLS 解析解**（NumPy 实现矩阵转置、乘法与求逆）：

```
β = (XᵀX)⁻¹ XᵀY
```

若 `XᵀX` 不可逆（`np.linalg.LinAlgError`），程序提示可能存在严重多重共线性并终止。

**拟合优度**：

```
R² = 1 − SSR / SST
```

其中 SSR（残差平方和）与 SST（总平方和）均通过逐样本循环手工累加。

## 📈 主要结果

拟合方程：

```
消费支出 = −3.7686 + 0.3992 × 年收入 + 0.0467 × 资产总值 + 0.1127 × 信心指数
```

| 变量 | 系数 | 经济学含义 |
|---|---|---|
| 截距 | −3.7686 | 基准项 |
| 年收入 | 0.3992 | 边际消费倾向（MPC）：收入每增 1 万元，消费平均增约 0.40 万元 |
| 资产总值 | 0.0467 | 财富效应：资产每增 1 万元，消费平均增约 0.047 万元 |
| 信心指数 | 0.1127 | 预期效应：信心指数每升 1 点，消费平均增约 0.11 万元 |

模型评估：SST = 91887.21，SSR = 19945.47，**R² = 0.7829** —— 三个自变量可解释消费支出约 78% 的变异，模型解释力良好。

## ⚠️ 局限与改进方向

- 均值填补会低估变量方差；负值一律置 0.1 属经验规则，可改用分位数缩尾或删除法对比
- 多元回归仅给出点估计与 R²，未做系数 t 检验、F 检验与残差诊断
- 以 `XᵀX` 是否可逆判断共线性过于宽松，可补充 VIF 或条件数检验
- R² > 0.6 的"良好"判据为启发式阈值，非统计检验结论
